# Your Next Cup support site

Static pages for the Your Next Cup iOS app. These files are separate from the app source.

## Pages

- `/` Home
- `/privacy/` Privacy Policy
- `/guide/` User Guide
- `/support/` Support

## Local preview

From this folder:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Publishing

This folder is intended to become its own GitHub repository, published with GitHub Pages from the `main` branch root.

Proposed repository: `your-next-cup`

Proposed public site: `https://jstrick428.github.io/your-next-cup/`

Do not publish until the privacy policy and support URLs are approved.

## Privacy of the site itself

These pages do not use analytics, cookies, tracking scripts, third-party fonts, advertising, a server, or a database.
